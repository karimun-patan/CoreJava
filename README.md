# Core Java Practice

A collection of Core Java programs that I practice daily to build my programming skills.

## About
I am learning Java and pushing one or more programs every day. This repository tracks my progress from basics to advanced topics.

## Topics Covered
- [x] Basics: Hello World, variables, data types
- [x] Operators and control statements (if, switch)
- [ ] Loops (for, while, do-while)
- [ ] Arrays
- [ ] Strings
- [ ] Methods
- [ ] OOP: classes, objects, inheritance, polymorphism
- [ ] Exception handling
- [ ] Collections


## How to Run
1. Clone the repository:
   `git clone https://github.com/karimun-patan/CoreJava.git`
2. Open it in Eclipse: File → Import → Existing Projects into Workspace
3. Open any program and click Run

## Tools Used
- Java (JDK version you use, e.g. 17)
